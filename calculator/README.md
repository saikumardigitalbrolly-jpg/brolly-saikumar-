# Brolly Academy Calculator

A responsive calculator app with standard arithmetic, scientific functions, calculation history, and student percentage/average tools.

## Run locally
Open `index.html` in a modern browser. No build step, server, account, API key, or database is required.

## Features
- Standard arithmetic, percentage, sign-ready negative values, backspace and clear.
- Scientific functions: trigonometry, inverse trigonometry, logarithms, square root, powers, factorial, pi and e.
- Degree/radian toggle.
- Local calculation history saved in browser storage.
- Keyboard input and copy result.
- Percentage and average student tools.
- Responsive black-and-yellow Brolly Academy-inspired design.

## Privacy and implementation
All calculations run in the browser. No `eval()`, backend, or external calculator API is used. History is stored locally in the current browser.

This is an independent learning utility inspired by the public Brolly Academy website; it is not an integration with the website.
